# Sistema de Biblioteca

Sistema de gerenciamento de biblioteca desenvolvido em Python com SQLite3 e OOP.

## Conteúdo
- `biblioteca_sistema.zip` — código-fonte completo

## Como executar
```bash
# Descompacte o zip e execute:
cd biblioteca
python main.py
```

## Tecnologias
- Python 3.10+
- SQLite3
- Paradigma: Orientação a Objetos (MVC)
- 3 tabelas relacionais: autores, livros, empréstimos
